        How the score is built

        Skill coverage

        Each skill on the target list your resume mentions adds points. The list is weighted — the deeper into the stack, the more it counts.

        Keyword context

        A skill named once in a list scores less than one described inside a project bullet. Context is what recruiters actually read.

        Structure

        Contact block, summary, experience, education. A parser has to find your sections before a human can skim them.

        FAQ

        Is my resume uploaded anywhere?

        No. This is a front-end mock — the file is read in your browser and nothing is sent to a server.

        How is my PDF read?

        With pdf.js, which runs in your browser and reads the PDF's text layer — the file is never uploaded. A scanned PDF is only an image of text, so it has no text layer and falls back to a sample resume.

        Can I change the target skill list?

        Yes — edit TARGET_SKILLS in app.js to match the roles you are applying for.
